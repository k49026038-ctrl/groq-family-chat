Как получить бесплатный ключ Groq:
  1. Перейдите в консоль console.groq.com/keys ↗
  2. Войдите через Google или GitHub аккаунт.
  3. Нажмите зеленую кнопку «Create API Key».
  4. Скопируйте сгенерированный ключ (начинается на gsk_) и вставьте его выше.

Groq LPU™ (Language Processing Unit)
Groq разработал инновационный тензорный процессор, оптимизированный исключительно для последовательного инференса больших языковых моделей (LLM).
⚡ Почему скорость до 1000 токенов/сек?
Традиционные GPU (NVIDIA H100/A100) используют внешнюю память HBM с высокой задержкой шины памяти. LPU размещает веса и вычисления в ультраскоростной статической памяти SRAM прямо на кристалле, обеспечивая пропускную способность до десятков терабайт в секунду без задержек.
